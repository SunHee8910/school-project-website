# School Project Website

A simple static website for a school project, designed for free GitHub Pages hosting from a public repository.

## Files

- `index.html`: the homepage, including its styling.
- `.nojekyll`: serves the files directly without Jekyll processing.

## View locally

Open `index.html` in a browser. No installation or build is needed.

## Publish on GitHub Pages

In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, select **main** and **/ (root)**, and save. GitHub displays the live website address on that page after deployment.

## Make updates

Edit `index.html`, commit the changes, and push to `main`. GitHub Pages automatically publishes the update. Publication may take a few minutes.

Use the provided `github.io` address to keep hosting free. No custom domain or paid services are needed. The repository and website are public; keep passwords and private information out of the files.
